TENTANG & SINKRON

Kenapa update dari upstream tidak akan bentrok

Launcher ini tidak mengubah satu pun file game. Semua yang baru ada di /launcher/ dan /sw.js. Kontrol sentuh disuntikkan ke halaman game saat dimuat oleh service worker, bukan ditulis ke index.html. Karena itu git merge upstream/main tidak pernah menyentuh file yang sama, dan workflow sinkron otomatis bisa jalan tanpa perlu diurus.

Kontrol sentuh itu mod biasa, bukan bagian launcher

Tidak ada satu baris pun kode kontrol sentuh di dalam launcher. Ia mod utuh di mods/mobile-controls/ dengan mod.json-nya sendiri, dan saat pertama dibuka launcher mengezipnya di memori lalu memasangnya lewat installMod() yang sama persis dengan zip buatanmu. Setelah itu ia baris biasa di database: bisa dimatikan, diurutkan, ditimpa mod lain, bahkan dihapus.

Yang launcher tahu cuma satu hal: folder mana yang berisi mod bawaan. Nama, versi, daftar file, dan skripnya semua dibaca dari mod.json milik mod itu. Tidak ada cabang kode "kalau ini mod bawaan" di mana pun — dan itu disengaja, karena setiap cabang seperti itu adalah tempat bug bersembunyi.

Pengaturan tombolnya ada di dalam game, bukan di sini: tombol KONTROL SENTUH di layar awal dan di menu jeda. Tombol itu ikut hilang kalau modnya dimatikan. Bawaannya tombol layar hanya muncul kalau ada layar sentuh — di browser desktop, setel selalu nyala di panel itu.

Cara kerja mod

Service worker memotong setiap permintaan file game. Kalau ada mod aktif yang punya file di path itu, isinya diambil dari IndexedDB. Tidak ada daftar file yang boleh dimod — path apa pun yang kamu taruh di zip, itulah yang dipakai. File asli di repo tidak pernah berubah; matikan mod, semuanya kembali seperti semula.

Mod tidak cuma mengganti — ia juga bisa menambah file. Path yang belum ada di repo tetap dilayani, jadi mod boleh membawa modul JS baru, tekstur baru, audio baru, atau data apa pun, lalu memanggilnya dari skripnya sendiri atau dari file yang ia ganti. Di daftar file tiap mod, yang menambah ditandai baru dan yang menimpa ditandai ganti.

Format mod

mod-saya.zip
├── mod.json
├── src/player.js          ← ganti logic pemain
├── src/weapons.js         ← ganti statistik senjata
├── styles.css             ← ganti tampilan menu
└── assets/audio/pistol-shot.mp3
{
  "name": "Mod Saya",
  "version": "1.0.0",
  "author": "kamu",
  "description": "Apa yang mod ini lakukan.",
  "scripts": ["mods/init.js"]
}

scripts opsional: file di daftar itu dijalankan sebagai modul setelah game siap, dengan window.DoodleMods dan window.__game tersedia. Berguna untuk tweak kecil tanpa menyalin seluruh file.
